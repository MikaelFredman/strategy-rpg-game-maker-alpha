# Security policy

Do not publish exploitable security vulnerabilities, private project data, tokens, or personal information in a public issue.

For the alpha, report a suspected security or data-loss problem through GitHub's private vulnerability reporting if enabled. If that option is unavailable, open a minimal issue stating that you need a private contact channel, without including exploit details or sensitive files.

Public game-project uploads must not contain executable code. Support for community uploads will require server-side schema validation, size limits, malware scanning, moderation, and version compatibility checks before it is enabled.
