# Strategy RPG Game Maker - Alpha Community

This repository is the public testing and feedback hub for the **Strategy RPG Game Maker** alpha.

The editor is a board-game-like 3D hex-map and game-authoring tool for offline Strategy RPG projects. It includes map, rules, teams, characters, items, dialogue, quests, tactical battle maps, loot, AI controllers, and spectator simulation.

## Alpha status

This is an early alpha, not a finished commercial release. Expect incomplete visual assets, balance changes, and saved-project migrations.

- Download the current package from [Strategy RPG Game Maker 0.1.0 Alpha 2](https://github.com/MikaelFredman/strategy-rpg-game-maker-alpha/releases/tag/v0.1.0-alpha.2).
- Read the release notes before installing a new version.
- Keep backup copies of important project files.
- The commercial engine source code is not hosted in this repository.

## Install on Windows

1. Download the Alpha 2 ZIP from the release link above.
2. Right-click the ZIP and choose **Extract All…**. Do not run the launcher from inside the ZIP.
3. Install the current [Node.js LTS](https://nodejs.org/) release if Node.js is not already installed.
4. Open the extracted folder and double-click **Start Strategy RPG Game Maker Alpha.cmd**.
5. Keep the launcher window open. The first start needs internet access to install the local runtime; later starts and ordinary editing work offline.

See [INSTALL.md](INSTALL.md) for troubleshooting and a first-test walkthrough. The package opens with the included **Ravenwood Pass** example, and the built-in **Help & Guide** explains editing and play from principles through detailed controls.

## Give feedback

- Use **Bug report** for reproducible failures.
- Use **AI or balance problem** when the simulator stalls, behaves irrationally, or produces consistently unfair results.
- Use **Feature request** for improvements and new capabilities.
- Use **Discussions** for questions, design ideas, screenshots, and showcases of games you created.

Please search existing reports before opening a new one. Include the alpha version, browser, Windows version, map size, exact reproduction steps, and screenshots when relevant.

## Sharing created games

Only share projects and media that you created or have permission to distribute. Do not upload executables or copyrighted third-party worlds, names, music, artwork, or stories without permission. Public project-file uploads will be introduced only after format validation and moderation are ready.

## Supported alpha environment

- Windows 10 or 11
- Current Chrome or Microsoft Edge
- Offline play after the package's documented initial setup
- Desktop/laptop layout; mobile and non-Chromium browsers are not currently supported
