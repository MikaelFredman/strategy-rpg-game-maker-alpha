# Contributing feedback

Thank you for helping test Strategy RPG Game Maker.

## A useful bug report

1. Confirm the issue occurs in the newest Beta Preview.
2. Search existing issues for the same behavior.
3. Describe the smallest repeatable sequence that causes it.
4. State what you expected and what happened instead.
5. Include version, browser, Windows version, map dimensions, and whether the project was newly created or migrated.
6. Attach screenshots or a minimal non-sensitive project file only when you have the right to share it.

Never upload passwords, API keys, personal data, private logs, paid assets, or third-party copyrighted game content.

## Feature requests

Explain the player or game-builder problem first. Then describe the proposed workflow, who benefits, and whether a simpler alternative exists.

## Triage

Reports are classified as:

- `blocker`: prevents installation, startup, saving, loading, or normal use
- `major`: important feature is broken without a reasonable workaround
- `minor`: limited impact or a practical workaround exists
- `suggestion`: improvement or new idea

This community repository does not accept engine source-code pull requests.
